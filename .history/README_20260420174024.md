"# Diary-Calendar" 
What's working in Phase 1
Layout & shell

Sticky ribbon: month/week label + 6 icon buttons (Today, Jump to date, Search, Sync, Add, Settings ···)
2-column week grid with Mon/Sun start logic — Sunday is always full-width, weekends are half-height
Edge navigation strips (top/bottom for week, left/right for month) + swipe gestures
Day cards

Day header, coloured event pills (blue=event, green=todo, amber=reminder), max 3 + "+N more"
Lined diary area (contenteditable, autosaves at 800ms debounce to localStorage)
Tap → expanded full-screen slide-up view; long-press (500ms) → quick-action sheet
Modals & overlays

Add/edit event sheet: type segmented control, date, time, repeat selector, notes
Settings dropdown: light/dark toggle, Mon/Sun week-start toggle, export/import JSON, clear all
Mini date picker: month grid, navigate months, jump to any date
Quick-action sheet: Add event/todo/reminder, Expand, Copy, Clear day
Data & state

localStorage persistence under chronicle_data; sample data pre-populated on first load
Undo stack (max 50 snapshots) — Ctrl+Z / Cmd+Z + Ctrl+Y
Android WebView safe-area (env(safe-area-inset-*)) throughout; 100dvh for keyboard awareness
Dark mode, desktop centering at 480px, all ARIA labels present
